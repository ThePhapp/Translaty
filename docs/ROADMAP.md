# Translaty Roadmap

## Phase 1 — Foundation

- React, TypeScript, Vite, Tauri 2, linting, formatting, and tests.
- Desktop-first application shell and provider abstraction.

## Phase 2 — MVP workflows

- Quick Translate with modes, language controls, and copy actions.
- Clipboard shortcut and compact translation workflow.
- SRT/VTT parse, preview, batch translation, and export.
- JSON i18n traversal, preview, translation, and export.
- Placeholder protection, deduplication, batching, progress, and cancellation.

## Phase 3 — Reuse and consistency

- SQLite translation memory and history.
- Relevant-term glossary injection with JSON/CSV import.
- Provider settings and OpenAI-compatible integration.

## Phase 4 — Expansion

- YAML localization files and batch folders.
- DeepL/Google adapters, provider health checks, and local models.
- OS keychain-backed credentials and richer review tools.
